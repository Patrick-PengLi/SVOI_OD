# Middleback / Iron Knob iron-oxide analog (WP4 Task 3 class, added 2026-09-23)

Second source class beside the basalt piles, on the advisor's recommendation: a
dense iron-oxide body of Middleback type. Admissible under the citation gate
because the Iron Knob ores were mined from 1900. Planned in WP4 Task 3 before
the Section 4 check; recorded here because Olympic Dam later proved to be a
hematite body, so the audit must see that the class predates the check.

Place the reports here by hand (SARIG, CC BY; all dated before t0). This folder lives only in
the SVOI_OD repo; the folder builder does not overwrite it.
- Bull 009 The Iron Ore Resources of South Australia.PDF
- RB3300090.pdf  Iron ore resources of the Middleback Range
- RB2600103.pdf  Magnetic surveys in the Middleback Ranges, Oct-Dec 1948
- RB3200029.pdf  Magnetic observations in the Middleback Range, 1950
- RB3200030.pdf  Magnetic observations in the Middleback Range, 1951
- RB3500031.pdf  Notes on proposed drill sites, Middleback Range
- RB3500060.pdf  Magnetic observations in the Middleback Range area, 1953

What they are for: body dimensions and shape (lens length, width, depth
extent), ore type (hematite vs magnetite, which sets susceptibility), and any
measured densities or magnetic contrasts. Property ranges otherwise come from
Parasnis 1973 (hematite 5.1, magnetite 5.2 g/cm3 pure) and the Task 3 range
3.0 to 4.5 g/cm3.
